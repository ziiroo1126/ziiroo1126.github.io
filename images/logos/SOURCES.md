# Institution logos

Prepared on 2026-10-21 for Zirui Wang's homepage. Logo artwork comes from the institutions' own websites.

## Stanford University - `stanford.png`

- Source page: https://identity.stanford.edu/visual-identity/stanford-logos/block-s/
- Original asset: https://identity.stanford.edu/wp-content/uploads/sites/3/2020/07/block-s-right.png
- 400 x 400 PNG with transparent background. Original file preserved without changes.

## Zhejiang University - `zhejiang.png`

- Source page: https://www.zju.edu.cn/514/listm.htm
- Original asset: https://www.zju.edu.cn/_upload/article/images/c3/98/1fb1d281492eb477a098ef7a2901/05966b26-ab45-470d-94c1-99b1e02d12f4.png
- 318 x 253 PNG. Original file preserved, including its white background and padding.

## Lanzhou University - `lanzhou.svg`

- Source page: https://ge.lzu.edu.cn/
- Original asset: https://ge.lzu.edu.cn/yjsxw/image/logo.svg
- The original SVG includes the circular university emblem and a wordmark. The viewBox is restricted to the emblem (0 0 122 120); paths and colors are unchanged.

The assets are used as inline institution icons in the About Me section. Display-only cropping and label styles are defined in `assets/css/main.scss`.
